# DUNLOP タイヤ電子荷票プロトタイプ

## 起動方法
同じフォルダー内の `index.html` をブラウザーで開いてください。

## 収録ページ
1. QRコード新規作成ページ
2. QRコードに対応した電子荷票ページ
3. 電子荷票一覧ページ

## 主な仕様
- QR単位: 銘柄・サイズ
- メーカー、保管場所は管理対象外
- フリー、売上予定・未払い、売上済み・未出庫、販売保留を表示
- 登録データはブラウザーの localStorage に保存
- QR生成ライブラリはCDN参照。インターネット未接続時はQR画像のみ生成されません。

## 注意
これは画面・業務フロー検証用です。本番化では Microsoft Entra ID 認証、Dataverse/SharePoint等の共有データベース、権限管理、同時更新制御、監査履歴を追加してください。

## QR識別票の印刷
電子荷票を開き、「QR識別票を印刷」を押してください。印刷対象は銘柄・サイズ・QRコード・管理番号を含む識別票のみです。印刷設定はA6縦、倍率100%を推奨します。

## 一覧表示
電子荷票一覧は、銘柄・サイズ、販売可能数、ステータス別内訳、最終更新日時を1商品1行で表示するリスト形式です。スマートフォンでは各行が縦方向に再配置されます。

## 担当者入力
初期在庫登録、および入庫・出庫・ステータス変更時に担当者をプルダウンから選択します。担当者は更新履歴に保存されます。現在は「担当者A」「担当者B」「担当者C」「管理者」の仮名です。

## 担当者の新規追加
ヘッダーの「担当者管理」、または担当者プルダウン横の「＋追加」から担当者名を登録できます。追加内容はブラウザーに保存され、初期在庫および各在庫操作の担当者プルダウンへ即時反映されます。空欄と重複名は登録できません。

## 修正履歴
- 担当者管理ボタンとJavaScript関数の名前衝突を解消しました。
- 旧バージョンで保存された4列の履歴を5列へ自動変換し、摘要が担当者欄に表示される問題を修正しました。旧履歴の担当者は「未設定」と表示します。

## 削除機能
- 担当者管理画面から登録済み担当者を削除できます。削除後はプルダウンに表示されませんが、過去履歴に記録済みの氏名は保持されます。
- 電子荷票ページから電子荷票を削除できます。在庫が0本より多い場合は、確認後に管理番号の再入力が必要です。電子荷票を削除すると、その荷票の在庫情報と更新履歴も削除されます。

## 実運用モード
`node server.js` で起動すると、在庫・担当者は `inventory-data.json` に共有保存されます。QRコードは `/tag/管理番号` の固定URLを格納するため、公開URL上では別のスマートフォンから該当電子荷票を直接開けます。

### ローカル確認
1. Node.js 18以上を用意
2. このフォルダーで `npm start`
3. `http://localhost:8080` を開く
4. `/api/health` が `{"ok":true}` を返すことを確認

### 公開時の必須設定
- Azure App ServiceなどNode.jsを実行できるHTTPS環境へフォルダー一式を配置
- 書き込み可能な永続ストレージを確保
- Microsoft Entra ID認証またはApp Service認証を有効化
- 公開後にQR識別票を再印刷。QRには公開ドメインの固定URLが入ります

### 重要
`file://`で直接開く方式は試作モードです。実運用では必ず `npm start` または公開サーバー経由で開いてください。サーバーを変更するとURLも変わるため、公開URL確定前に本番QRを印刷しないでください。
